# Project Brief

## Project

ATELIER is a premium casual food concept centered on burgers, panini, hot dogs, desserts, and drinks.

## Phase 0 Objective

Create a clean technical foundation, not the final website design.

The foundation should make it easy to add final content, photography, menu details, visual identity, and deployment settings later without restructuring the project.

## Technical Direction

- Vite
- Vanilla JavaScript modules
- Static JSON content
- Mobile-first CSS
- English and Greek locale support
- Static hosting friendly output

## Current Scope

Included:

- Project scaffold
- Section rendering modules
- Bilingual placeholder content
- Placeholder menu categories
- CSS architecture
- Documentation

Not included:

- Final art direction
- Final menu copy and pricing
- Production imagery
- Analytics
- CMS integration
- Online ordering
- Reservations

## Primary Pages

Phase 0 uses one page with these sections:

- Header
- Hero
- Concept
- Featured items
- Menu
- Gallery
- Contact
- Footer
